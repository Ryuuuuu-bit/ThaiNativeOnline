# นายพราน (hunter) model and animations

Current runtime body: the user's `rangers-user.glb`, with clips and the bow
retargeted from the legacy model below. Rebuild with
`tools/class-models/README.md`; running this composer alone builds the legacy body.
The current portrait is rendered from the replacement runtime model.

`hunter-tripo.glb` is the hunter and bow from Tripo (generated by the owner), prepared in
Blender:

1. hunter decimated from 1.9 M to ~27 k triangles, textures 1024²; bow to ~7.6 k, 512²;
2. skinned to the Muay Thai fighter's Tripo skeleton (`tools/muaythai-anims/fighter-tripo.glb`):
   the two T-poses match (height 0.98, arm span 0.82), so the armature is used as is and the
   vertex weights are transferred from the fighter's body (Data Transfer, nearest face
   interpolated);
3. the bow is parented to `mixamorig:LeftHand`, its grip through the fist (string toward
   the body, so thumb-up = bow upright), scaled to 0.78 of the body height;
4. exported with the fighter's source clips (walk, run, jab …), which play unchanged.

```sh
npm i --no-save @gltf-transform/core@4 @gltf-transform/functions@4
node tools/hunter-anims/compose.mjs tools/hunter-anims/hunter-tripo.glb public/models/hunter.glb
```

`compose.mjs` reuses the fighter's procedural pose builder (`fighter()`: hinge limbs, leg
and arm IK, palm roll split into the forearm) and keys the archer's poses: ready, side-on
aim (bow arm straight at shoulder height, string hand anchored under the jaw, elbow high),
release. Clip list and timings: `docs/art/classes/hunter/ANIMATIONS.md`.
Legacy portrait workflow: Eevee render of the full-resolution model.
Skill icons: PixelLab 48×48 art in `tools/icons/source/hunter/`, framed by `tools/icons/normalize.py`.
