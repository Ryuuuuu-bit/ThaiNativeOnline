# Thai Native Online

แผนที่ต้นแบบสำหรับเกม RPG แฟนตาซีไทยยุคกรุงศรีอยุธยา สร้างด้วย Three.js และ Vite

## เริ่มใช้งาน

ต้องใช้ Node.js 22.12+ (หรือเวอร์ชันใหม่ที่ Vite รองรับ)

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal สำหรับ production ใช้ `npm run build` และตรวจด้วย `npm run preview`

## แผนที่แรก: ป่าริมวัดร้าง

- กล้อง Orthographic มุม 2.5D รองรับหน้าจอ Full HD 1920 × 1080 และปรับตามขนาดหน้าจอ
- ป่าเขตร้อน ต้นไม้ใบกว้าง กอไผ่ หญ้าแบบ instancing พร้อม shader ลม
- พื้นผิว procedural 2048 × 2048 ทางดิน เงาแสงเช้าและแสงเย็น
- เจดีย์ทรงระฆัง ซากกำแพงอิฐ ศาลาไม้หลังคาไทย ศาลเจ้าป่า และคลองบัว
- ละอองแสง ใบไม้ร่วง น้ำเคลื่อนไหว และเสียงลมกับนกที่สร้างด้วย Web Audio
- เดินสำรวจ ชนสิ่งกีดขวาง แผนที่ย่อ และการสำรวจจุดสำคัญ

## ตัวละคร 6 อาชีพ

นักรบ มวยไทย นักฆ่า หมอผี หมอยา และพราน (พร้อมสุนัขคู่ใจ) สร้างตาม concept sheet เป็นโมเดลที่ rig ด้วยโครงกระดูก humanoid ชื่อแบบ Mixamo ขาใช้ IK สองข้อต่อ ข้อต่อจำกัดมุมตามสรีระ ชายผ้าและพู่ใช้ spring bone แต่ละอาชีพมีท่ายืน เดิน วิ่ง และสามท่าเฉพาะจาก concept sheet

- เลือกอาชีพในแผงตัวละครมุมซ้ายบน
- ห้องตัวละคร `characters.html` ใช้ดูโครงกระดูก เล่นทุกท่า และ export เป็น `.glb`
- `npm run check:rig` ตรวจทุกเฟรมของทุกท่าว่าเท้าไม่จมพื้น ไม่ไถล และข้อต่อไม่เกินช่วง

รายละเอียดอยู่ใน [docs/character-rig.md](docs/character-rig.md)

## ควบคุม

| การกระทำ | ปุ่ม |
| --- | --- |
| วิ่ง | W A S D / ลูกศร / ปุ่มสัมผัสบนมือถือ |
| เดิน | กด Shift ค้างพร้อมทิศทาง |
| ใช้ท่าเฉพาะอาชีพ | 1 2 3 / ปุ่มบนแถบท่า |
| เดินไปยังจุด | คลิกพื้น (เส้นตรง ไม่มี pathfinding; ใช้ WASD เดินอ้อม) |
| เลื่อนมุมกล้อง | ลากเมาส์ขวา |
| ซูม | Scroll |
| คืนมุมกล้อง | R |
| สำรวจจุดสำคัญ | E / แตะข้อความสำรวจ |
| ซ่อน UI ชมแผนที่ | H |
| ปิดแผงตั้งค่า | Escape |

ภาพ โมเดล และท่าทางทั้งหมดสร้างจาก geometry และ canvas ในโค้ด ไม่มี assets เกมจากแหล่งอื่น ฟอนต์ Noto โหลดจาก Google Fonts และมี system fallback เมื่อ offline สถาปัตยกรรมเป็นการตีความเพื่อเกม ไม่ใช่แบบจำลองโบราณคดี

## ขอบเขตเวอร์ชัน 0.1

เวอร์ชันนี้เน้น map และการเดินสำรวจ แถบสถานะผู้เดินทางเป็น UI ต้นแบบ ยังไม่มีระบบต่อสู้ EXP ดรอปไอเท็ม บอส multiplayer หรือ persistence

โครงสร้าง: `src/world.js` สร้างโลก; `src/characters/` ตัวละคร rig และท่าทาง; `src/main.js` จัดการ render, controls, UI และเสียง; `src/viewer.js` ห้องตัวละคร; `src/style.css` จัดหน้าจอ
