# Thai Native Online

MMORPG ผีไทยแนว Ragnarok Online เล่นในเบราว์เซอร์ สร้างด้วย Three.js + Vite ฝั่งเกม และ Node.js (WebSocket + Postgres) ฝั่งเซิร์ฟเวอร์ ฉากเป็นอโยธยาแฟนตาซี กลางวันเป็นเมืองค้าขาย กลางคืนเป็นป่าผี

เป้าหมายการออกแบบ: เก็บเลเวลยากและช้าแบบ RO ของทุกชิ้นมีค่า ไม่มีฟาร์มออฟไลน์ ทุกอย่างที่แตะไอเทม ทอง EXP หรือความยุติธรรม ตัดสินบนเซิร์ฟเวอร์ ([`docs/technical/SERVER_SPLIT.md`](docs/technical/SERVER_SPLIT.md))

## เริ่มใช้งาน

ต้องใช้ Node.js 20+ (แนะนำ 22)

```sh
npm install
npm run dev        # Vite dev server (client อย่างเดียว เล่นแบบออฟไลน์ มอนสเตอร์รันในเบราว์เซอร์)
npm run build      # สร้าง dist/
npm start          # เซิร์ฟเวอร์เกมเสิร์ฟ dist/ + WebSocket ที่ /ws (ต้อง build ก่อน)
npm test           # ชุดทดสอบ 283 ตัวใน Node ไม่ต้องเปิดเบราว์เซอร์
```

เล่นออนไลน์จริงต้องรันผ่าน `npm start` (ค่าเริ่มต้นพอร์ต 8080) การเล่นผ่าน `npm run dev` ไม่มีเซิร์ฟเวอร์ จึงเป็นโหมดเดี่ยวสำหรับพัฒนาและซ้อมสกิล

### ตัวแปรแวดล้อมของเซิร์ฟเวอร์

| ตัวแปร | ความหมาย |
| --- | --- |
| `PORT` | พอร์ต (ค่าเริ่มต้น 8080) |
| `DATABASE_URL` | Postgres สำหรับบัญชีและเซฟ ถ้าไม่ตั้งจะเก็บในหน่วยความจำ (หายเมื่อปิด) |
| `GOOGLE_CLIENT_ID` | เปิดปุ่มเข้าสู่ระบบด้วย Google |
| `GM_ID`, `GM_PASSWORD` | สร้างบัญชี GM ตอนเริ่มเซิร์ฟเวอร์ (หรือใช้ `ADMIN_IDS` รายชื่อบัญชีคั่นด้วย ,) |

Deploy อยู่บน Railway: push ขึ้น `main` แล้ว UAT build เอง

5 แมพต่อกันด้วยประตูวาปและทางเดิน ระดับมอนสเตอร์ไล่จากเมืองออกไป (`src/world/maps.js`, `src/data/spawns.js`, [`docs/world/WORLD_MAP.md`](docs/world/WORLD_MAP.md))

| แมพ | ระดับ | บรรยากาศ |
| --- | --- | --- |
| นครอโยธยา | เขตปลอดภัย | ท่าเรือ ตลาด ย่านช่าง ลานฝึก วัด NPC 57 ตัวมีตารางชีวิตกลางวัน–กลางคืน |
| ทุ่งนาข้าว | 1–3 | หมูป่า ลิงกัง ไก่ป่า งูเห่านา ปูนา · ควายป่า (อีลิท) |
| ป่าลึก | 2–5 | ผีป่า ผีพราย วิญญาณเร่ร่อน หมาไน เหี้ย ผีโขมด ผีกองกอย · นางตะเคียน |
| วัดร้าง | 4–8 | ผีตายโหง ผีวัดร้าง ผีหัวขาด เปรตน้อย ผีกระหัง · ผีปู่โสม กระสือ |
| คลองหนองบึง | 10–25 | ปลิงควาย ผีพรายน้ำ จระเข้บึง งูเหลือม ผีโพง ผีตายทั้งกลม กุมภีล์ ผีนางรำ · นางตานี ชาละวัน |

- นาฬิกาโลกหนึ่งวัน = 24 นาทีจริง เซิร์ฟเวอร์เป็นเจ้าของเวลา บางชนิดเกิดเฉพาะกลางวันหรือกลางคืน ผีแรงขึ้นตอนกลางคืน
- มอนสเตอร์มีพฤติกรรมเฉพาะตัว: ฝูงช่วยกัน ชาร์จ ดึง โล่หน้า เรียกลูกน้อง พิษ ดูด MP ไก่ป่าวิ่งเข้าใส่ทุกคน
- บอสและอีลิทเกิดทีละตัว รอนาน (4–20 นาที) และมีเฉพาะ CH 1 ช่องสัญญาณ (channel) เปิด–ปิดตามจำนวนคน
- มอนสเตอร์เป็นสไปรต์พิกเซลแบบ RO (ป้ายหันเข้ากล้อง 8 ทิศ idle/เดิน/ตี/ตาย `public/sprites/monsters/`, `src/combat/MonsterSprites.js`) สลับเป็นโมเดล 3D ได้ในตั้งค่ากราฟิก ตัวที่ยังไม่มีสไปรต์ใช้โมเดลอัตโนมัติ · สร้างชีทจาก PixelLab ด้วย `node tools/pixel-monsters/fetch.mjs`

## อาชีพ

6 อาชีพ เล่นได้ 5 (โจรป่ายังไม่มีชุดสกิล) แต่ละอาชีพมีสกิล 10 ท่าพร้อมโมเดล 3D และท่าทางเฉพาะ (`src/classes/`, `public/models/`)

| อาชีพ | สาย | จุดเด่น |
| --- | --- | --- |
| มวยไทย | ประชิด | ศอก เข่า ไหว้ครู หนุมาน |
| นักรบ | ประชิด | ดาบ โล่ ธง |
| นายพราน | ระยะไกล | ธนู กับดัก หมาคู่ใจ (กัดเอง มีสัญชาตญาณพุ่งกัด) |
| หมอผี | เวท | อาคม ยันต์ คุณไสย |
| หมอยา | สนับสนุน | ฮีลตัวเองและปาร์ตี้ ชุบชีวิต ตำรายาลอยรอบตัว |

- Base Lv สูงสุด 99, Job Lv สูงสุด 50 ให้แต้มสกิล 49 แต้ม · สกิลละ 10 เลเวล รวม 100 เลเวล จึงต้องเลือกสาย: ต้นไม้สกิลของแต่ละอาชีพมี 3 สาย (เป้าเดียว/บอส · ฟาร์มหมู่ · ซัพพอร์ต/แทงก์) สกิลปลดเมื่อสกิลก่อนหน้าในสายถึงเลเวลที่กำหนดและถึง Job ขั้นต่ำ (`src/character/data/skilltree.js`) แต่ละสายมีสกิลติดตัว 1 ตัวข้างสาย (ปลดเมื่อสกิลแรกของสาย Lv 3, `src/rules/data/kitpassives.js`) · สกิล Lv 5 เลือกสายวิวัฒน์ A/B ได้ · รีเซ็ตแต้มเสียทองตาม Job Lv
- การ์ดสกิล (K) แสดง "ของคุณตอนนี้": ดาเมจ/การรักษาที่คำนวณจาก ATK/MATK ของตัวละครจริง จำนวนครั้ง คริ คูลดาวน์หลัง DEX และบอกว่าสกิลแรงขึ้นจากค่าไหน · หน้าตัวละคร (C) มี "คู่มือลงแต้ม": ค่าหลักของอาชีพ แผนลงแต้มแนะนำ 2–3 แบบ พร้อมปุ่มลงแต้มที่เหลือตามสัดส่วน และกติกาสูตรดาเมจ (`src/character/data/statguide.js`)
- ค่าสถานะ STR AGI VIT INT DEX LUK ลงเองทุกเลเวล รีเซ็ตได้ ([`docs/design/STATS_REFERENCE.md`](docs/design/STATS_REFERENCE.md))
- EXP ต่อคิลตามส่วนต่างเลเวลแบบ RO (+2%/เลเวลที่มอนสูงกว่า สูงสุด +20%, ห่าง 10+ ลดลง, ต่ำกว่ามาก −10%/เลเวล) และหนึ่งคิลไม่เกิน 20% ของเลเวล บอสถึงหนึ่งเลเวล
- ตายเสียทอง 10% เกิดใหม่ 60% HP บัฟและสถานะทุกอย่างหายเมื่อตาย

## ระบบ

**ต่อสู้** เลือกเป้า ตีปกติ (เร็วตาม AGI) สกิลมีเวลาร่าย คูลดาวน์ ระยะ และ AoE แบบวง/แนว/พัด คริ หลบ สถานะมึน ช้า พิษ แผลเรื้อรัง ตัวเลขดาเมจที่เห็นเป็นผลสุ่มของเซิร์ฟเวอร์ สกิลและเอฟเฟกต์ของผู้เล่นคนอื่นมองเห็นกัน

**AUTO (G)** เลือกสกิล ลำดับเป้า (ตัวที่ตีเรา → บอส → ใกล้สุด) รัศมีหาเป้า ดื่มยาตาม % สกิลเอาตัวรอดเมื่อเลือดต่ำ (ไม่มีนั่งพักฟื้น: ฟื้นด้วยยาและหมอยา) เดินอ้อมต้นไม้เอง เปลี่ยนเป้าถ้าไปไม่ถึง ทำงานต่อแม้สลับแท็บ ใช้ได้เฉพาะออนไลน์

**ไอเทม** กระเป๋ามีช่องและน้ำหนัก (หนักแล้ว HP/MP ไม่ฟื้น) อุปกรณ์ 8 ช่อง อาวุธสองมือ (ธนู กระบี่) การ์ดมอนสเตอร์ใส่ของตามชนิด ถอดการ์ดที่หมออาคม (เสี่ยงพัง) **ตีบวก** ถึง +10 ที่หมื่นเพชรศาสตรา (ปลอดภัยถึง +4 พังแล้วของหาย) ร้านค้าหลายประเภทต้องยืนใกล้ NPC

**ออนไลน์** บัญชี (รหัสผ่านหรือ Google) ตัวละคร 4 ช่องเล่นจากเครื่องไหนก็ได้ เซฟบน Postgres เล่นแบบผู้มาเยือนได้แต่เซฟอยู่ในเบราว์เซอร์และตั้งปาร์ตี้กับผู้เล่นที่ล็อกอินไม่ได้ · เห็นผู้เล่นอื่นพร้อมชื่อ อาชีพ เลเวล ฉายา · แชทรวม กระซิบ `/w` · **ปาร์ตี้** 6 คน แบ่ง EXP เมื่ออยู่ใกล้ (โบนัส 10%) · **แลกเปลี่ยน** ล็อก–ยืนยันสองฝ่าย · เพื่อน · จัดอันดับและฉายา · ตัวเลขดาเมจเหนือหัว (ไม่มี DPS meter) · คำสั่ง GM (`/gm`)

**เควส** รับจาก NPC เป้าหมายแบบสำรวจ ปราบ เก็บของ คุย ต้องยืนใกล้ NPC ตอนรับและส่ง ของรางวัลต้องมีที่ว่างก่อน

## เซิร์ฟเวอร์ (`server/`)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.js` | HTTP + WebSocket, บัญชี, การเดินเรื่องข้อความทั้งหมด, tick 10 Hz |
| `presence.js` | ใครอยู่แมพไหน ตำแหน่ง (ตรวจความเร็ว ปฏิเสธการวาร์ป เปลี่ยนแมพผ่านประตูเท่านั้น) ห้องและช่องสัญญาณ |
| `monsters.js` | มอนสเตอร์หนึ่งชุดต่อแมพ: เกิด ไล่ ตี กลับบ้าน ตาย แบ่งรางวัล |
| `combatants.js` | สำเนาตัวละครของผู้เล่น: ทอยดาเมจ MP คูลดาวน์ เวลาร่าย จำกัดจำนวนครั้งตีต่อ cast สถานะ ฮีล ชุบ |
| `progress.js` | เล่นซ้ำการกระทำกับไอเทม/สถานะ/เควสบนสำเนาเซิร์ฟเวอร์ โหลด–เซฟ |
| `parties.js`, `trades.js`, `channels.js`, `ranking.js`, `gm.js`, `accounts.js`, `store.js` | ปาร์ตี้ แลกเปลี่ยน ช่องสัญญาณ อันดับ คำสั่ง GM บัญชี Postgres |

สูตรทั้งหมดอยู่ใน `src/rules/`, `src/training/kitCombat.js` และ `src/character/` ซึ่งไม่แตะ DOM ทั้งเบราว์เซอร์และเซิร์ฟเวอร์จึงรันโค้ดเดียวกัน

## ประสิทธิภาพ
