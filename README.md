# Thai Native Online

MMORPG ผีไทยแนว Ragnarok Online เล่นในเบราว์เซอร์ สร้างด้วย Three.js + Vite ฝั่งเกม และ Node.js (WebSocket + Postgres) ฝั่งเซิร์ฟเวอร์ ฉากเป็นอโยธยาแฟนตาซี กลางวันเป็นเมืองค้าขาย กลางคืนเป็นป่าผี

เป้าหมายการออกแบบ: เก็บเลเวลยากและช้าแบบ RO ของทุกชิ้นมีค่า ไม่มีฟาร์มออฟไลน์ ทุกอย่างที่แตะไอเทม ทอง EXP หรือความยุติธรรม ตัดสินบนเซิร์ฟเวอร์ ([`docs/technical/SERVER_SPLIT.md`](docs/technical/SERVER_SPLIT.md))

## เริ่มใช้งาน

ต้องใช้ Node.js 20+ (แนะนำ 22)

```sh
npm install
npm run dev        # Vite dev server (client อย่างเดียว เล่นแบบออฟไลน์ มอนสเตอร์รันในเบราว์เซอร์)
npm run build      # สร้าง dist/
npm start          # เซิร์ฟเวอร์เกมเสิร์ฟ dist/ + WebSocket ที่ /ws (ต้อง build ก่อน)
npm run server     # เซิร์ฟเวอร์อย่างเดียว ใช้คู่กับ npm run dev เพื่อเล่นออนไลน์ระหว่างพัฒนา
npm test           # ชุดทดสอบ ~920 ตัวใน 124 ไฟล์ (node --test) ไม่ต้องเปิดเบราว์เซอร์
```

เล่นออนไลน์จริงต้องรันผ่าน `npm start` (ค่าเริ่มต้นพอร์ต 8787) ถ้ารัน `npm run dev` อย่างเดียวจะไม่มีเซิร์ฟเวอร์ เป็นโหมดเดี่ยวสำหรับพัฒนาและซ้อมสกิล ถ้ารัน `npm run server` คู่กันด้วย Vite จะส่งต่อ `/ws` ไปที่พอร์ต 8787 ให้เล่นออนไลน์ได้

### ตัวแปรแวดล้อมของเซิร์ฟเวอร์

| ตัวแปร | ความหมาย |
| --- | --- |
| `PORT` | พอร์ต (ค่าเริ่มต้น 8787) |
| `DATABASE_URL` | Postgres สำหรับบัญชีและเซฟ ถ้าไม่ตั้งจะเก็บในหน่วยความจำ (หายเมื่อปิด) |
| `GOOGLE_CLIENT_ID` | เปิดปุ่มเข้าสู่ระบบด้วย Google |
| `GM_ID`, `GM_PASSWORD` | สร้างบัญชี GM ตอนเริ่มเซิร์ฟเวอร์ `GM_ID` เป็นแอดมินที่ถอดไม่ได้ |
| `ADMIN_IDS` | รายชื่อแอดมินหลักคั่นด้วย `,` (ถอดไม่ได้) แอดมินคนอื่นเพิ่มด้วย `/gm admin add` และเก็บถาวรในฐานข้อมูล |

Deploy อยู่บน Railway เฉพาะ UAT (<https://thainative-uat.up.railway.app/>) push ขึ้น `main` แล้ว build เอง ยังไม่มี production ([`docs/technical/deployments/`](docs/technical/deployments/))

## โลกของเกม

14 แมพ: เมือง 1, เขตล่า 4, ห้องบอสโลก 1 และแมพสำรวจสำหรับปาร์ตี้ 8 แมพ ระดับมอนสเตอร์ไล่จากเมืองออกไปจนถึง Lv 100 (`src/world/maps.js`, `src/world/expeditions.js`, `src/data/spawns.js`, [`docs/world/WORLD_MAP.md`](docs/world/WORLD_MAP.md), [`docs/world/LEVEL_PROGRESSION.md`](docs/world/LEVEL_PROGRESSION.md))

| --- | --- | --- |

| ป่าลึก | 3–9 | หมาไน เหี้ย ผีกองกอย ผีโขมด · เสือสมิง (อีลิท เฉพาะกลางคืน) นางตะเคียน |
| วัดร้าง | 5–14 | เปรตน้อย ผีหัวขาด ผีกระหัง ผีตายโหง ทหารผีเฝ้าวัด · กระสือ (อีลิท) ผีปู่โสม (บอส) |

| เรือนหอร้าง | บอสโลก | ห้อง instance เปิดเฉพาะกลางคืน เข้าจากปุ่มข่าวบอสโลก |
| แมพสำรวจ 8 แมพ | 23–100 | ปาร์ตี้ 3–5 คน: ป่าช้าไผ่ดำ · เหมืองอาคมร้าง · นครบาดาล · ป้อมอสูรสนธยา · หุบเขายักษ์ · ป่าหิมพานต์ · นครอาคมล่มสลาย · ประตูรอยแยกอสูร แต่ละแมพมีบอสท้ายแมพ |

- **การเดินทาง:** เมือง↔ทุ่งนาผ่านวาร์ปประตูเหนือ ทุ่งนา→ป่าลึก→วัดร้าง→คลองหนองบึงเป็นทางเดินต่อกัน คลองหนองบึงมี "ประตูป่าช้า" ไปแมพสำรวจแรก แมพสำรวจต่อกันด้วย "ประตูเดินทาง" และ "ประตูกลับ" ผู้ดูแลการเดินทาง (6 จุดในเมือง และ 1 จุดในทุกแมพ) พาวาร์ปฟรี (`src/data/warpServices.js`) และกด B เพื่อคืนเมือง (คูลดาวน์ 30 วินาที)
- **จุดล่า:** ทุกแมพมีจุดล่าแบ่งตามระดับ เขตล่า 8–12 จุด แมพสำรวจ 12 จุด (3 วง × 4 จุด) (`src/data/hunting.js`, `src/world/HuntingGrounds.js`)
- นาฬิกาโลกหนึ่งวัน = 24 นาทีจริง เซิร์ฟเวอร์เป็นเจ้าของเวลา บางชนิดเกิดเฉพาะกลางวันหรือกลางคืน ผีแรงขึ้นตอนกลางคืน
- มอนสเตอร์มีพฤติกรรมเฉพาะตัว: ฝูงช่วยกัน ชาร์จ ดึง โล่หน้า เรียกลูกน้อง พิษ ดูด MP ไก่ป่าวิ่งเข้าใส่ทุกคน
- มอนสเตอร์เป็นโมเดล 3D ทั้งหมด (`public/models/monsters/` 37 ตัวจาก Meshy พร้อมท่าทางเฉพาะชนิด) ตัวที่ยังไม่มีโมเดลใช้ mesh ที่สร้างจากโค้ด สไปรต์พิกเซลเดิมเลิกใช้แล้ว
- **บอส** เกิดทีละตัว รอนาน และมีเฉพาะ CH 1 บอสแต่ละตัวมีสกิลเตือนล่วงหน้า 2 ท่า (กรวย วงเล็ง วงแหวน) ใช้เวลาง้าง 1.8–2.4 วินาที และล็อกเป้าตอนเริ่มเตือน จึงหลบได้ (`src/combat/bossSkills.js`, [`docs/technical/BOSS_ENCOUNTERS.md`](docs/technical/BOSS_ENCOUNTERS.md))
- **บอสโลก ผีชุดแดง · ผีชุดดำ** ตื่นคืนละครั้งที่เรือนหอร้าง HP เพิ่มตามจำนวนคนออนไลน์ มี 5 ระดับ (12/30/50/75/99) สองตัวผูกกัน: ตัวหนึ่งล้มต้องล้มอีกตัวภายใน 12 วินาที ไม่งั้นฟื้น (`src/combat/data/worldBoss.js`)
- ช่องสัญญาณ (channel) เปิด–ปิดตามจำนวนคน

## อาชีพ

6 อาชีพ เล่นได้ 5 (โจรป่ายังไม่มีชุดสกิล) แต่ละอาชีพมีสกิล 10 ท่าพร้อมโมเดล 3D ที่ rig แล้วและท่าทางเฉพาะ (`src/classes/`, `public/models/`) แต่ละสายสกิลมีบทบาทในปาร์ตี้ต่างกัน และได้โบนัสเมื่อโจมตีศัตรูที่ติดสถานะจากเพื่อน สูงสุด 25% ([`docs/design/CLASS_SKILL_SYNERGY.md`](docs/design/CLASS_SKILL_SYNERGY.md))

อาวุธแยกชนิดตามอาชีพแบบ RO: นักรบ ดาบ · นายพราน ธนู · มวยไทย ผ้าพันมือ · โจรป่า มีดคู่ · หมอผี ผ้ายันต์ · หมอยา ตำรา (`WEAPON_KINDS` ใน `src/character/data/classes.js`, `Character.canWield`) อาวุธของอาชีพอื่นใส่ไม่ได้ (เก็บ/ขาย/เทรดได้) แต่ละชนิดมี 3 ขั้น (เริ่มต้น · หายาก Lv ~8 · คลองหนองบึง) ไม้เท้าเดิมถูก retire แล้ว (โหลดเซฟแล้วได้ทองคืนอัตโนมัติ หมอยาเก่าได้ตำราเล่มแรกแทน) ไอคอนไอเทมมาจาก PixelLab แล้วใส่กรอบด้วย `tools/icons/frame_items.py`

| อาชีพ | สาย | จุดเด่น |
| --- | --- | --- |
| มวยไทย | ประชิด | ศอก เข่า ไหว้ครู หนุมาน · ทำให้อ่อนแรงและเจาะเกราะ |
| นักรบ | ประชิด | ดาบ โล่ ธง · ยั่วและปกป้องเพื่อน |
| นายพราน | ระยะไกล | ธนู กับดัก หมาคู่ใจ (กัดเอง มีสัญชาตญาณพุ่งกัด) · ทำให้ช้า ตรึง และเปิดจุดอ่อน |
| หมอผี | เวท | อาคม ยันต์ คุณไสย · ลดป้องกันหรือดาเมจศัตรู คุมฝูง |
| หมอยา | สนับสนุน | ฮีลตัวเองและปาร์ตี้ ชุบชีวิต ล้างสถานะ ตำรายาลอยรอบตัว |

- Base Lv สูงสุด 100, Job Lv สูงสุด 50 ให้แต้มสกิล 49 แต้ม · สกิลละ 10 เลเวล รวม 100 เลเวล จึงต้องเลือกสาย: ต้นไม้สกิลของแต่ละอาชีพมี 3 สาย (เป้าเดียว/บอส · ฟาร์มหมู่ · ซัพพอร์ต/แทงก์) สกิลปลดเมื่อสกิลก่อนหน้าในสายถึงเลเวลที่กำหนดและถึง Job ขั้นต่ำ (`src/character/data/skilltree.js`) แต่ละสายมีสกิลติดตัว 1 ตัวข้างสาย (ปลดเมื่อสกิลแรกของสาย Lv 3, `src/rules/data/kitpassives.js`) · ทุกสกิลและสกิลติดตัวเลือกสายวิวัฒน์ A/B ได้ (เลือกครั้งแรกฟรี เปลี่ยนเสียทอง Job Lv × 10) · รีเซ็ตแต้มเสียทองตาม Job Lv
- เควสอาชีพ 12 เควส: บทนำที่ Lv 5 และขั้นสูงที่ Lv 20 (`src/data/quests.js`)
- การ์ดสกิล (K) แสดง "ของคุณตอนนี้": ดาเมจ/การรักษาที่คำนวณจาก ATK/MATK ของตัวละครจริง จำนวนครั้ง คริ คูลดาวน์หลัง DEX และบอกว่าสกิลแรงขึ้นจากค่าไหน · หน้าตัวละคร (C) มี "คู่มือลงแต้ม": ค่าหลักของอาชีพ แผนลงแต้มแนะนำ 2–3 แบบ พร้อมปุ่มลงแต้มที่เหลือตามสัดส่วน และกติกาสูตรดาเมจ (`src/character/data/statguide.js`)
- ค่าสถานะ STR AGI VIT INT DEX LUK ลงเองทุกเลเวล รีเซ็ตได้ ([`docs/design/STATS_REFERENCE.md`](docs/design/STATS_REFERENCE.md))
- EXP ต่อคิลตามส่วนต่างเลเวลแบบ RO (+2%/เลเวลที่มอนสูงกว่า สูงสุด +20%, ห่าง 10+ ลดลง, ต่ำกว่ามาก −10%/เลเวล) และหนึ่งคิลไม่เกิน 20% ของเลเวล บอสถึงหนึ่งเลเวล
- ตายเสียทอง 10% เกิดใหม่ 60% HP บัฟและสถานะทุกอย่างหายเมื่อตาย

## ระบบ

**ต่อสู้** เลือกเป้า ตีปกติ (เร็วตาม AGI) สกิลมีเวลาร่าย คูลดาวน์ ระยะ และ AoE แบบวง/แนว/พัด คริ หลบ สถานะมึน ช้า พิษ แผลเรื้อรัง ตัวเลขดาเมจที่เห็นเป็นผลสุ่มของเซิร์ฟเวอร์ สกิลและเอฟเฟกต์ของผู้เล่นคนอื่นมองเห็นกัน

**AUTO (G)** เลือกสกิล ลำดับเป้า (ตัวที่ตีเรา → บอส → ใกล้สุด) รัศมีหาเป้า ดื่มยาตาม % สกิลเอาตัวรอดเมื่อเลือดต่ำ (ไม่มีนั่งพักฟื้น: ฟื้นด้วยยาและหมอยา) เดินอ้อมต้นไม้เอง เปลี่ยนเป้าถ้าไปไม่ถึง ทำงานต่อแม้สลับแท็บ ใช้ได้เฉพาะออนไลน์

**ไอเทม** คลังเก็บของของบัญชี 120 ช่องที่เคาน์เตอร์ในเมือง ล็อกไอเทม ชุดอุปกรณ์ 3 ชุด · กระเป๋ามีช่องและน้ำหนัก (หนักแล้ว HP/MP ไม่ฟื้น) อุปกรณ์ 8 ช่อง อาวุธสองมือ (ธนู กระบี่) การ์ดมอนสเตอร์ใส่ของตามชนิด ถอดการ์ดที่หมออาคม (เสี่ยงพัง) **ตีบวก** ถึง +10 ที่หมื่นเพชรศาสตรา (ปลอดภัยถึง +4 พังแล้วของหาย) ร้านค้าหลายประเภทต้องยืนใกล้ NPC ขายของทีละหลายชิ้นได้ในครั้งเดียว

**ออนไลน์** บัญชี (รหัสผ่านหรือ Google และแสดงรูปโปรไฟล์ Google บน HUD) ตัวละคร 4 ช่องเล่นจากเครื่องไหนก็ได้ ชื่อตัวละครห้ามซ้ำทั้งเซิร์ฟเวอร์ บัญชีและตัวละครมี UID ถาวร (`ACC-…`, `CHR-…`) คัดลอกได้จากหน้าบัญชี เซฟบน Postgres เล่นแบบผู้มาเยือนได้แต่เซฟอยู่ในเบราว์เซอร์และตั้งปาร์ตี้กับผู้เล่นที่ล็อกอินไม่ได้ · เห็นผู้เล่นอื่นพร้อมชื่อ อาชีพ เลเวล ฉายา · แชทแยกแท็บ ทั่วไป ปาร์ตี้ กระซิบ ระบบ · **ปาร์ตี้** 6 คน แบ่ง EXP เมื่ออยู่ใกล้ (โบนัส 10%) กระดานหาปาร์ตี้ และเดินตามหัวหน้า · **แลกเปลี่ยน** ล็อก–ยืนยันสองฝ่าย บันทึกถาวรไม่หายแม้เซิร์ฟเวอร์รีสตาร์ต · **PK เสรี** ตั้งแต่ Lv 20 นอกเมือง (คนต่ำกว่า Lv 20 ตีและโดนตีไม่ได้) พร้อมแต้มบาป · บุญ ยศหน้าชื่อ ชื่อสีส้ม/แดงตามบาป และฉายา PK ([`docs/design/PVP_KARMA.md`](docs/design/PVP_KARMA.md)) · ดวลแบบยินยอมทุกเลเวล · เพื่อน · จัดอันดับและฉายา · ตัวเลขดาเมจเหนือหัว (ไม่มี DPS meter) · คำสั่ง GM (`/gm`) เห็นเฉพาะแอดมิน และจัดการแอดมินด้วย `/gm admin add|remove|list`

**เควส** รับจาก NPC เป้าหมายแบบสำรวจ ปราบ เก็บของ คุย ต้องยืนใกล้ NPC ตอนรับและส่ง ของรางวัลต้องมีที่ว่างก่อน ดูเควสทั้งหมดได้ในสมุดเควสจากเมนูหลัก

**แผนที่โลก (M)** แสดงทุกแมพพร้อมตัวกรอง ร้านค้า ครู เดินทาง จุดล่า ถิ่นบอส สถานที่ กดรายการแล้วเดินไปเอง · สมุดมอนสเตอร์บันทึกตัวที่เคยพบ

**เสียง** เพลงประกอบ 10 อารมณ์สังเคราะห์ด้วย Web Audio (ไม่มีไฟล์เสียง) เปลี่ยนตามแมพ ย่าน กลางวัน–กลางคืน การต่อสู้ และบอส (`src/audio/LocationMusic.js`, `src/data/calmMusic.js`)

## เซิร์ฟเวอร์ (`server/`)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.js` | HTTP + WebSocket, บัญชี, การเดินเรื่องข้อความทั้งหมด, tick 10 Hz |
| `presence.js` | ใครอยู่แมพไหน ตำแหน่ง (ตรวจความเร็ว ปฏิเสธการวาร์ป เปลี่ยนแมพผ่านประตูเท่านั้น) ห้องและช่องสัญญาณ |
| `monsters.js` | มอนสเตอร์หนึ่งชุดต่อแมพ: เกิด ไล่ ตี กลับบ้าน ตาย แบ่งรางวัล |
| `combatants.js` | สำเนาตัวละครของผู้เล่น: ทอยดาเมจ MP คูลดาวน์ เวลาร่าย จำกัดจำนวนครั้งตีต่อ cast สถานะ ฮีล ชุบ |
| `progress.js` | เล่นซ้ำการกระทำกับไอเทม/สถานะ/เควสบนสำเนาเซิร์ฟเวอร์ โหลด–เซฟ |
| `parties.js`, `party-board.js`, `trades.js`, `trade-service.js`, `channels.js`, `ranking.js` | ปาร์ตี้ กระดานหาปาร์ตี้ แลกเปลี่ยน (บันทึกถาวร) ช่องสัญญาณ อันดับ |
| `gm.js`, `gm-catalog.js`, `gm-authority.js`, `adminRoles.js` | คำสั่ง GM สิทธิ์ และรายชื่อแอดมินถาวร |
| `accounts.js`, `store.js`, `uids.js`, `character-names.js`, `save-queue.js` | บัญชี Postgres UID ถาวร ชื่อตัวละครห้ามซ้ำ คิวเซฟ |
| `stash.js`, `class-quests.js`, `service-warp.js`, `recall.js`, `pvp.js` | คลังเก็บของ เควสอาชีพ วาร์ป คืนเมือง ดวลและ PK |
| `interest.js`, `navigation.js`, `shutdown.js` | ส่งข้อมูลเฉพาะสิ่งที่อยู่ใกล้แต่ละคน ตรวจการเดินด้วย collision ที่ bake ไว้ ปิดเซิร์ฟเวอร์อย่างปลอดภัย |

สูตรทั้งหมดอยู่ใน `src/rules/`, `src/training/kitCombat.js` และ `src/character/` ซึ่งไม่แตะ DOM ทั้งเบราว์เซอร์และเซิร์ฟเวอร์จึงรันโค้ดเดียวกัน

## ประสิทธิภาพ

อาคารรวม mesh ตามวัสดุทีละ chunk 40×40 พืชพรรณและของประกอบฉากเป็น InstancedMesh หญ้าเป็น GPU field ชุดเดียวตามกล้อง NPC ใช้ instanced mesh ร่วมกันและอัปเดตตามระยะ โมเดลอาชีพแต่ละไฟล์โหลดครั้งเดียวแล้ว clone ให้ผู้เล่นทุกคน ไม่มี dynamic light นอกจากดวงอาทิตย์ เกณฑ์ที่ 1920×1080 ราว 200–450 draw calls ([`docs/technical/PERFORMANCE_BUDGET.md`](docs/technical/PERFORMANCE_BUDGET.md))
