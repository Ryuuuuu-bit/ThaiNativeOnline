# Thai Native Online

เกม RPG แฟนตาซีไทยแรงบันดาลใจจากกรุงศรีอยุธยา สร้างด้วย Three.js และ Vite

## เริ่มใช้งาน

ต้องใช้ Node.js 22.12+ (หรือเวอร์ชันใหม่ที่ Vite รองรับ)

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal สำหรับ production ใช้ `npm run build` และตรวจด้วย `npm run preview`

## อาชีพที่เล่นได้

ตอนสร้างตัวละครเลือกได้ 2 อาชีพ (อาชีพอื่นยังล็อกเป็นเงาดำ — `?classes=all` ปลดล็อกเพื่อทดสอบ):

- **มวยไทย** และ **หมอยา**: โมเดล 3D จาก Tripo พร้อมสกิล 10 ท่า ลองสกิลได้ที่หุ่นฟางใกล้ท่าเรือ (ปุ่ม 1–0, Q ออโต้)
- หมอยาใช้สกิลพร้อมตำรายาที่ลอยวนรอบตัว

โค้ด: `src/classes/` (สกิลและ FX ของแต่ละอาชีพ), `src/training/` (ลานซ้อมในเมือง)

## ควบคุม

ภาพ ตัวละคร และเสียงทั้งหมดสร้างจาก geometry, canvas และ Web Audio ในโค้ด ไม่มี assets เกมจากแหล่งอื่น ฟอนต์ Noto โหลดจาก Google Fonts และมี system fallback เมื่อ offline

**นครอโยธยา (`/`)**

| การกระทำ | ปุ่ม |
| --- | --- |
| เดิน / วิ่ง | W A S D / ลูกศร · กด Shift ค้างเพื่อวิ่ง |
| เดินไปยังจุด | คลิก/แตะพื้น (หาทางอ้อมสิ่งกีดขวางอัตโนมัติด้วย `src/core/GridPath.js`) |
| คุยกับ NPC / สำรวจสถานที่ | E (กดซ้ำเพื่อคุยต่อ, Esc ปิด) |
| แผนที่ทั้งเมือง | M |
| เลื่อนกล้อง / ซูม / คืนมุมกล้อง | ลากเมาส์ขวา / Scroll / R |
| ซ่อน UI | H |
| โหมดผู้พัฒนา (FPS, draw calls, กราฟทางเดิน NPC, จุดเกิดมอนสเตอร์) | F3 |

ตั้งค่าในเกมได้ทั้งเวลาของโลก (หมุนเวียน เช้า กลางวัน เย็น กลางคืน) ความเร็วเวลา แรงลม คุณภาพภาพ และละอองแสง

พารามิเตอร์ URL สำหรับทดสอบ เช่น `?at=0,28&t=22&zoom=0.8&debug` ใช้วางตำแหน่ง ล็อกชั่วโมง ซูม และเปิดโหมดผู้พัฒนา ส่วน `ui=0` ซ่อน UI

## ตัวละคร การต่อสู้ และ UI (`src/character/`, `src/combat/`)

รายละเอียด interface อยู่ใน [`src/character/README.md`](src/character/README.md) และ [`src/combat/README.md`](src/combat/README.md)

- **6 อาชีพ** ตามคอนเซปต์ ได้แก่ มวยไทย นักรบ นายพราน (มีหมาคู่ใจ) หมอผี หมอยา และโจรป่า ตอนนี้เลือกได้เฉพาะ**มวยไทย**และ**หมอยา** เลือกเพศชายหรือหญิงได้ แต่ละอาชีพมี 4 ทักษะ ตั้งชื่อและเลือกอาชีพตอนเข้าเกมครั้งแรก ข้อมูลบันทึกไว้ใน localStorage
- **ตัวละคร** มีค่าสถานะ เลเวลและ EXP กระเป๋า อุปกรณ์สวมใส่ และขายของได้
- **การต่อสู้** มีการเลือกเป้า โจมตีอัตโนมัติ คริติคอล การหลบ สถานะผิดปกติ ของดรอป และการตาย
- **ตอนนี้ยังไม่มีมอนสเตอร์** เมืองเป็นเขตปลอดภัย (`src/data/spawns.js` ว่าง) ลองสกิลได้ที่หุ่นฟาง
- **ช่วงเวลาของโลก** ช่วงกลางคืนของนาฬิกาโลกคือช่วงกลางคืนของการต่อสู้ กด `N` เพื่อสลับกลางวันกับกลางคืนทันที

| การกระทำ | ปุ่ม |
| --- | --- |
| เลือกเป้าถัดไป / คลิกมอนสเตอร์ | Tab / คลิกซ้าย |
| โจมตีปกติ / ทักษะ | Space / 1–4 |
| ยา HP / ยา MP | Q / F |
| หน้าตัวละคร / กระเป๋า | C / I |
| สลับกลางวัน–กลางคืน | N |

### โมเดลตัวละคร 3D (`public/models/`)

ทุกอาชีพใช้โมเดล GLB จาก Tripo (rig ชื่อกระดูกแบบ Mixamo) ตั้งค่าใน `AVATARS` ที่ `src/data/training.js` ตอนนี้มีมวยไทยและหมอยา อาชีพที่ยังไม่มีโมเดลจะใช้โมเดลมวยไทยไปก่อน ทุกครั้งที่ใช้ทักษะจะเล่นท่าของโมเดลตาม `casts` วิธีทำโมเดลอาชีพใหม่ดูที่ `docs/art/classes/<อาชีพ>/PRODUCTION.md`

## ระบบหลัก

- **เวลาของโลก** (`core/WorldClock.js`) แบ่งเป็นเช้า กลางวัน เย็น และกลางคืน หนึ่งวันใช้เวลาจริง 24 นาทีโดยค่าเริ่มต้น แสง หมอก น้ำ โคมไฟ และตารางชีวิต NPC เปลี่ยนตามเวลา
- **NPC** 57 ตัว (`data/npcs.js`) อาชีพ รูปลักษณ์ ร้านค้า และตารางเวลาเป็นข้อมูลทั้งหมด
  - สถานะ: Idle / Walk / Talk / Work / Sit
  - เดินตามจุดบนกราฟถนน (A* ใน `npc/NavGraph.js`) จึงไม่เดินลงน้ำหรือทะลุอาคาร และเปลี่ยนเป็น navmesh ได้ภายหลังโดยไม่ต้องแก้ข้อมูล
  - กลางคืนร้านปิด ชาวเมืองกลับบ้าน ทหารออกตระเวน พระบิณฑบาตตอนเช้า
  - ทหารมี `faction: 'city_guard'` และ `NPCManager.guardsNear()` เตรียมไว้สำหรับระบบ Karma/PvP
- **จุดเกิดมอนสเตอร์** (`data/spawns.js`) ประกาศพื้นที่และช่วงเวลา ส่วน `combatSpawns()` เลือกมอนสเตอร์ของแต่ละพื้นที่ (ชนิดจาก `src/combat/data/monsters.js`) ส่งให้ระบบต่อสู้ ตอนนี้ว่างอยู่
- **ร้านค้า** (`shop/ShopSystem.js`, `ui/ShopPanel.js`) พ่อค้าที่มี `stock` ใน `data/shops.js` มีปุ่ม "ซื้อ-ขาย" ในหน้าต่างสนทนา ซื้อตามราคาไอเท็ม ขายคืนได้ครึ่งราคา ร้านที่ยังไม่มี stock และการฝึกวิชาแสดงเป็นฟีเจอร์ในอนาคต
- **เควส** (`data/quests.js`, `quest/QuestSystem.js`, `ui/QuestUI.js`) ตอนนี้มี 1 เควสในเมือง ระบบรองรับเป้าหมายแบบสำรวจสถานที่ / ปราบมอนสเตอร์ / เก็บไอเท็ม / คุยกับ NPC มีเควสก่อนหน้าและเลเวลขั้นต่ำ ป้ายชื่อ NPC แสดง `!` (มีเควสให้รับ) `?` (ส่งได้) `…` (กำลังทำ) และติดตามความคืบหน้าในบันทึกการเดินทาง ความคืบหน้าและสถานที่ที่ค้นพบบันทึกใน localStorage

## ประสิทธิภาพ

- อาคารสร้างจาก geometry ในโค้ด แล้วรวม mesh ตามวัสดุทีละ chunk ขนาด 40×40 (`world/Batching.js`) ทำให้ frustum culling ทำงานและ shadow pass วาดเฉพาะบริเวณใกล้
- พืชพรรณและของประกอบฉากใช้ InstancedMesh แยกตาม chunk ส่วนหญ้าใช้ GPU field ชุดเดียวที่เคลื่อนตามกล้องและอ่าน density mask จึงมีต้นทุนเท่ากันทุกจุดของแผนที่
- NPC ทั้งหมดใช้ instanced mesh ร่วมกันราว 30 ชุดไม่ว่าจะมีกี่ตัว และอัปเดตตามระยะห่าง: ใกล้ทุกเฟรม กลาง 5 Hz ไกล 1 Hz และซ่อนเมื่อไกลมาก
- ไม่มี dynamic light นอกจากดวงอาทิตย์และ hemisphere โคมไฟใช้ emissive, sprite และแสงบนพื้นแบบ instanced กล้องเงาเคลื่อนตามผู้เล่นและ snap ตาม texel
- เกณฑ์ที่วัดได้ (1920×1080) ประมาณ 200–450 draw calls ที่ซูมปกติ (สูงสุดราว 630 เมื่อซูมออกสุด) และ 0.55–0.9 ล้านสามเหลี่ยม ขึ้นกับพื้นที่ การสร้างโลกใช้เวลาประมาณ 1.5 วินาที

## ขอบเขตและขั้นต่อไป

เวอร์ชันนี้มีโลก เมือง ตัวละคร การต่อสู้ ร้านค้า และเควสพื้นฐานแล้ว ยังไม่มีระบบออนไลน์ การตีบวก หรือการฝึกวิชา ตัวละครในฉากยังเป็นโมเดลเดียวกันทุกอาชีพ

1. การตีบวกที่โรงหลอมศาสตรา (ต้องให้ Character เก็บระดับบวกของอุปกรณ์ จึงรอ Character Agent)
2. โมเดลตัวละครแยกตามอาชีพและเพศ
3. ค่ากรรม (Karma) และการตอบสนองของทหารเมือง
4. Navmesh สำหรับ NPC (ผู้เล่นใช้ A* แบบ grid ใน `src/core/GridPath.js` แล้ว)
