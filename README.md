# Thai Native Online

เกม RPG แฟนตาซีไทยแรงบันดาลใจจากกรุงศรีอยุธยา สร้างด้วย Three.js และ Vite

## เริ่มใช้งาน

ต้องใช้ Node.js 22.12+ (หรือเวอร์ชันใหม่ที่ Vite รองรับ)

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal สำหรับ production ใช้ `npm run build` และตรวจด้วย `npm run preview`

ตั้งค่าในเกมได้ทั้งเวลาของโลก (หมุนเวียน เช้า กลางวัน เย็น กลางคืน) ความเร็วเวลา แรงลม คุณภาพภาพ และละอองแสง

พารามิเตอร์ URL สำหรับทดสอบ เช่น `?at=0,-530&t=22&zoom=0.8&debug` ใช้วางตำแหน่ง ล็อกชั่วโมง ซูม และเปิดโหมดผู้พัฒนา ส่วน `ui=0` ซ่อน UI

## ระบบหลัก

- **เวลาของโลก** (`core/WorldClock.js`) แบ่งเป็นเช้า กลางวัน เย็น และกลางคืน หนึ่งวันใช้เวลาจริง 24 นาทีโดยค่าเริ่มต้น แสง หมอก น้ำ โคมไฟ และตารางชีวิต NPC เปลี่ยนตามเวลา
- **บรรยากาศตามพื้นที่** (`world/Environment.js`) ยิ่งลึกเข้าป่ายิ่งมืด หมอกหนาขึ้น และนกเงียบลง ใกล้สุสานจะมีหมอกต่ำและดวงวิญญาณ ซึ่งชัดขึ้นในเวลากลางคืน
- **NPC** 64 ตัว (`data/npcs.js`) อาชีพ รูปลักษณ์ ร้านค้า และตารางเวลาเป็นข้อมูลทั้งหมด
  - สถานะ: Idle / Walk / Talk / Work / Sit
  - เดินตามจุดบนกราฟถนน (A* ใน `npc/NavGraph.js`) จึงไม่เดินลงน้ำหรือทะลุอาคาร และเปลี่ยนเป็น navmesh ได้ภายหลังโดยไม่ต้องแก้ข้อมูล
  - กลางคืนร้านปิด ชาวเมืองกลับบ้าน ทหารออกตระเวน พระบิณฑบาตตอนเช้า
  - ทหารมี `faction: 'city_guard'` และ `NPCManager.guardsNear()` เตรียมไว้สำหรับระบบ Karma/PvP
- **จุดเกิดมอนสเตอร์** (`data/spawns.js`) ประกาศพื้นที่และช่วงเวลา ระบบต่อสู้ใน `src/game/` สร้างมอนสเตอร์ตามพื้นที่เหล่านี้
- **ร้านค้า** (`shop/ShopSystem.js`, `ui/ShopPanel.js`) พ่อค้าที่มี `stock` ใน `data/shops.js` มีปุ่ม "ซื้อ-ขาย" ในหน้าต่างสนทนา ซื้อตามราคาไอเท็ม ขายคืนได้ครึ่งราคา ร้านที่ยังไม่มี stock และการฝึกวิชาแสดงเป็นฟีเจอร์ในอนาคต
- **เควส** (`data/quests.js`, `quest/QuestSystem.js`, `ui/QuestUI.js`) 7 เควส เป้าหมายแบบสำรวจสถานที่ / ปราบมอนสเตอร์ / เก็บไอเท็ม / คุยกับ NPC มีเควสก่อนหน้าและเลเวลขั้นต่ำ ป้ายชื่อ NPC แสดง `!` (มีเควสให้รับ) `?` (ส่งได้) `…` (กำลังทำ) และติดตามความคืบหน้าในบันทึกการเดินทาง ความคืบหน้าและสถานที่ที่ค้นพบบันทึกใน localStorage

## ตัวละคร ต่อสู้ และ UI (`src/game/`)

- **6 อาชีพ**: มวยไทย, นักรบ, นายพราน (มีหมาคู่ใจ), หมอผี, หมอยา, โจรป่า เลือกเพศได้ แต่ละอาชีพมี 4 ทักษะ
- **ตัวละคร**: ค่าสถานะ พลัง/ว่องไว/ปัญญา/อึด, เลเวลและ EXP, แต้มสถานะ, กระเป๋า 24 ช่อง, สวมอาวุธ/เสื้อ/เครื่องราง, ขายของ, บันทึกอัตโนมัติใน localStorage
- **ต่อสู้**: เลือกเป้า, โจมตีอัตโนมัติ, global cooldown, คริติคอล, หลบ, ติดสถานะ (ช้า, พิษ), buff, AI มอนสเตอร์ (เดินเล่น ไล่ล่า ถอยกลับ), ดรอปของ, ตายแล้วฟื้นที่ศาลเจ้าปากป่า
- **มอนสเตอร์ตามเวลาของโลก** (`game/citySpawns.js` อ่านพื้นที่จาก `data/spawns.js`):

| พื้นที่ | เช้า–เย็น | กลางคืน |
| --- | --- | --- |
| ปากป่า / ป่าทึบ / ป่าลึก | หมูป่า, ลิงกัง | ผีป่า, ผีพราย, **เสือสมิง** (หัวหน้า) |
| ทางเข้าสุสาน / ศาลร้าง | วิญญาณเร่ร่อน (ตั้งแต่เย็น) | วิญญาณเร่ร่อน |
| สุสาน | – | ผีตายโหง, **กระสือ** (Rare 50%), **ปอบ** (บอส Lv.10) |

  กลางคืน EXP +25% ผีแรงขึ้น 20% โจรป่าคริติคอลเพิ่ม 12% และ UI เปลี่ยนเป็นธีมแสงจันทร์

## ประสิทธิภาพ

- อาคารสร้างจาก geometry ในโค้ด แล้วรวม mesh ตามวัสดุทีละ chunk ขนาด 40×40 (`world/Batching.js`) ทำให้ frustum culling ทำงานและ shadow pass วาดเฉพาะบริเวณใกล้
- พืชพรรณและของประกอบฉากใช้ InstancedMesh แยกตาม chunk ส่วนหญ้าใช้ GPU field ชุดเดียวที่เคลื่อนตามกล้องและอ่าน density mask จึงมีต้นทุนเท่ากันทุกจุดของแผนที่
- NPC ทั้งหมดใช้ instanced mesh ร่วมกันราว 30 ชุดไม่ว่าจะมีกี่ตัว และอัปเดตตามระยะห่าง: ใกล้ทุกเฟรม กลาง 5 Hz ไกล 1 Hz และซ่อนเมื่อไกลมาก
- ไม่มี dynamic light นอกจากดวงอาทิตย์และ hemisphere โคมไฟใช้ emissive, sprite และแสงบนพื้นแบบ instanced กล้องเงาเคลื่อนตามผู้เล่นและ snap ตาม texel
- เกณฑ์ที่วัดได้ (1920×1080) ประมาณ 200–450 draw calls ที่ซูมปกติ (สูงสุดราว 630 เมื่อซูมออกสุด) และ 0.55–0.9 ล้านสามเหลี่ยม ขึ้นกับพื้นที่ การสร้างโลกใช้เวลาประมาณ 1.5 วินาที

## โครงสร้างโค้ด

```
src/
  core/      Game, InputManager, CameraController, WorldClock, AudioAmbience
  world/     World (ประกอบโลก), CityMap (ภูมิศาสตร์ ถนน น้ำ), Terrain, Water, Vegetation,
             Architecture (ชุดสร้างอาคารไทย), props, Collision, Batching, Environment, Atmosphere
  world/districts/  Walls, Port, Market, Shops, Temple, Countryside, Wilds, Fill, Nature
  entities/  Player, NPC, Boats, Animals
  npc/       NPCManager, NPCData (อาชีพ/รูปลักษณ์), NPCSchedule, NavGraph, NPCRenderer
  ui/        HUD, Minimap, ShopPanel, QuestUI
  quest/     QuestSystem (ตรรกะเควส ไม่ขึ้นกับ DOM)
  shop/      ShopSystem (ซื้อ-ขาย ผ่าน API สาธารณะของ Character)
  game/      Character, Combat, CombatView, GameUI, data (อาชีพ ทักษะ มอนสเตอร์ ไอเท็ม), citySpawns
  data/      npcs, shops, quests, landmarks, regions, spawns
```

ภาพและโมเดลทั้งหมดสร้างจาก geometry และ canvas ในโค้ด ไม่มี assets เกมจากแหล่งอื่น ฟอนต์ Noto โหลดจาก Google Fonts และมี system fallback เมื่อ offline เจดีย์ร้าง ซากกำแพง และศาลเจ้าป่าจากต้นแบบแรกถูกนำมาใช้ในป่าของแผนที่ใหม่

## ขอบเขตและขั้นต่อไป

ยังไม่มีระบบออนไลน์ การตีบวก หรือการฝึกวิชา ตัวละครในฉากยังเป็นโมเดลเดียวกันทุกอาชีพ

1. การตีบวกที่โรงหลอมศาสตรา (ต้องให้ Character เก็บระดับบวกของอุปกรณ์ จึงรอ Character Agent)
2. โมเดลตัวละครแยกตามอาชีพและเพศ
3. ค่ากรรม (Karma) และการตอบสนองของทหารเมือง
4. Navmesh / pathfinding สำหรับผู้เล่นและ NPC
