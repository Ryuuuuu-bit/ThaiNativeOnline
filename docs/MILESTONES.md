# Milestones

## Milestone 0 — Art Benchmark Scene
Create a small ~30m x 30m scene containing:
- one player character
- 3 trees
- 3 rocks
- grass
- dirt path
- Thai house
- small shrine
- water
- one NPC
- one monster
- final gameplay camera, lighting, shadow, and materials

Goal: produce the first screenshot that defines “this is Thai Native Online”.
