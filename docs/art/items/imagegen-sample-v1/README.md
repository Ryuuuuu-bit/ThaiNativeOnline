# ImageGen item icon sample v1

Twelve representative existing Lv.50 Dusk Fort item definitions plus tier-six HP/MP flasks, produced as individual transparent PNG previews. Runtime item definitions and deployed icons are unchanged by this sample.

Open `/ui/items/imagegen-sample-v1/preview.html` on the project's Vite server to compare full-size artwork and 32/48/64 px thumbnails on jade, light and checker backgrounds. The gallery labels are shortened for presentation; `manifest.json` records the actual item IDs and provenance. `prompts.md` records the complete built-in ImageGen prompts.

Style: soft painted Thai fantasy, jade cloth/leather and restrained antique-gold fittings. Headgear stays a cloth turban. Jewelry has distinct necklace/ring silhouettes; HP and MP flasks differ in body shape as well as color. Frames, rarity, refinement, socket counts, hotkeys and charge meters remain UI overlays.

Source PNGs are generation masters rather than optimized shipping textures. Selection, thumbnail readability review and production texture export precede any runtime replacement. This sample does not create weapon models or change item balance.
