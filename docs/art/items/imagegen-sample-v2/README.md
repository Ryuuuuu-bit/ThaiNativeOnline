# Thai ornament and sacred accessory previews v2

Fifteen individual transparent ImageGen samples extend the approved twelve-item jade/brass family. The original v1 assets remain available for comparison.

The twelve existing samples receive selective kanok metal borders, prajam-yam medallions and embroidered cloth edges while keeping their silhouettes and material/color blocks. The necklace now contains a recognizable seated-Buddha amulet in a pointed gilt frame. Three existing game item definitions receive additional previews: `takrut` (rolled metal talisman), `bia_kae` (cowrie protective amulet) and `prakam` (agarwood prayer beads).

Open `/ui/items/imagegen-sample-v2/preview.html` on the Vite server for jade/light/checker background comparison and actual 32/48/64 px thumbnails. A link returns to the original twelve-item gallery. Full generation/edit prompts and provenance are in `prompts.md` and `manifest.json`.

This remains an asset sample: runtime item definitions, balance, existing deployed images and models are unchanged. Production exports must preserve alpha and be sized/compressed for actual game slots before runtime replacement.
