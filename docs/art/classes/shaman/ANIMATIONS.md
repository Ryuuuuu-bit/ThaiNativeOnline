# หมอผี — ร่ายคาถาด้วยมือเปล่า

ใช้โมเดล `wizzard.glb` ที่ผู้ใช้ส่งเมื่อ 2026-10-08 เก็บต้นฉบับไว้ที่
`tools/shaman-anims/wizzard-tripo.glb` มี Mixamo rig แต่ไม่มีคลิปในไฟล์ต้นฉบับ
สร้างคลิปบน rig ใหม่นี้ โดยคงท่าร่ายด้วยมือและเวลาเอฟเฟกต์เดิม
สร้างคลิปด้วย `tools/shaman-anims/compose.mjs` และคงเวลาเอฟเฟกต์ตาม `src/classes/shaman-moves.js`

ทุกสกิลเริ่มจากประสานมือสลับสัญลักษณ์ นิ้วชี้และนิ้วกลางเหยียด นิ้วที่เหลืองอ
จากนั้นปล่อยคาถาด้วยฝ่ามือ โดยยังคงเสื้อผ้าและเครื่องรางแบบหมอผีไทย

| Clip | ท่าปล่อยคาถา |
| --- | --- |
| shaman_akom / shaman_yant / shaman_kalp | ผลักสองฝ่ามือไปด้านหน้า |
| shaman_ward | กางฝ่ามือสร้างเกราะ |
| shaman_thunder / shaman_curse | ย่อตัว กดสองมือลงพื้น |
| shaman_holy / shaman_ghostfire / shaman_storm | กางมือหงายเรียกวิญญาณ |
| shaman_meditate | ประสานมือ แล้วลดมือซ้อนกันทำสมาธิ |

มี idle, walk, run, hurt, die ครบ ไม้เท้าถูกถอดจากไฟล์ผลลัพธ์ แต่เก็บไฟล์ต้นฉบับไว้

ท่า idle เป็นท่าพร้อมร่ายแบบอนิเมะ: มือขวายกใกล้หน้าอก เหยียดนิ้วชี้/กลาง
มือซ้ายผ่อนข้างตัว เท้าเหลื่อมหน้า–หลังและลำตัวหันเล็กน้อย แต่ศีรษะมองหน้า
การหายใจขยับเฉพาะลำตัวช่วงบน ไม่ขยับสะโพกหรือเท้า คลิปยาว 2.6 วินาที
ทุกสกิลกลับเข้าท่าพร้อมร่ายเดียวกัน รวมถึงนิ้วมือ โดยคงเวลาปล่อยเอฟเฟกต์เดิม
ภาพตรวจงาน: `docs/art/reviews/shaman-idle/selection-stage.png`

แกนนิ้วอ้างอิงระนาบฝ่ามือและข้อจริงของ rig นี้ (ไม่มี bone ปลายนิ้วลำดับ 4)
นิ้วงอเข้าฝ่ามือ ไม่หักย้อน จำกัด MCP/PIP/DIP ประมาณ 66°/80°/49°
นิ้วโป้งใช้การหมุนเข้าหาฝ่ามือแยกจากนิ้วอื่น ตรวจทุกคลิปที่ 30 fps

โมเดลใหม่ใช้ผมสั้น ชุดแดงดำ ผ้ายันต์และเครื่องรางตามไฟล์ที่ผู้ใช้ส่ง
มีภาพ portrait ใหม่ให้ตรงกับตัวละครในเกม ใช้ texture สูงสุด 1024px และ meshopt
ไฟล์พร้อมเล่นประมาณ 1.41 MB ต้นฉบับที่ผู้ใช้ส่งไม่ถูกแก้ไข

ข้อจำกัด: แอนิเมชันเป็นการสร้างท่าบน rig ใหม่ ไม่ใช่ motion capture ของโมเดลนี้
ผ้าและเครื่องรางติดไปกับ skin ไม่มี cloth simulation
