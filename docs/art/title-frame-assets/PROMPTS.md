# ImageGen title and profile frame prompts

Built-in `image_gen.imagegen` used for all fourteen originals, with `transparent_background: true`; no API/CLI fallback or paid 3D generation. Frame text and portraits are composed from the live UI, never generated into these images. Normalized runtime files live in `public/ui/titles/imagegen-v1/`; companion admission receipts record dimensions, alpha, byte sizes and hashes. Original PNGs are retained outside shipped assets.
