# Camera Guide

Target: orthographic / near-orthographic 2.5D gameplay camera.

The camera must support:
- strong player silhouette
- clear walkable paths
- readable enemy telegraphs
- stable environment scale
- minimal perspective distortion

Do not switch the core game to third-person or cinematic close-camera gameplay without Game Director approval.

Every new character/environment set should be reviewed from the gameplay camera, not only close-up.
