# Environment Guide

Environment should feel rich around the player but never hide navigation.

Asset principles:
- modular kits
- large readable shapes
- clustered foliage
- soft hand-painted materials
- controlled detail frequency
- clear collision
- LOD/instancing readiness

First benchmark kit:
3 tree shapes, 3 rocks, grass, dirt path, one Thai house, one small shrine, water, props, one NPC staging point.
