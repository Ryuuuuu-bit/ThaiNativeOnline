# Character Guide

Target proportions: stylized anime MMORPG, roughly 5-6 heads tall unless a deliberate exception is approved.

Priority:
1. silhouette
2. class identity
3. hair/head shape
4. weapon/fighting identity
5. costume color blocks
6. Thai details
7. small decoration

Deliverables for production concepts:
front, back, side, 3/4, and gameplay-camera preview.
