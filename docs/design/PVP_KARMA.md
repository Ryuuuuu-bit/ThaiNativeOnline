# PK เสรี · บาป · บุญ · ยศ

กติกาทั้งหมดอยู่ใน `src/data/karma.js` (ตัวเลขปรับได้ที่ `KARMA`) เซิร์ฟเวอร์เป็นผู้ตัดสิน (`server/pvp.js`, `server/index.js`) ส่วน `src/net/PvpPanel.js` แสดงผล

## ใครตีใครได้

| เงื่อนไข | ผล |
| --- | --- |
| ทั้งคู่ Lv 20 ขึ้นไป อยู่นอกเมือง แชนแนลเดียวกัน และล็อกอินแล้ว | ตีกันได้ทันที ไม่ต้องยินยอม (PK เสรี) |
| ผู้โจมตีต่ำกว่า Lv 20 | ตีไม่ได้ (`level`) |
| เป้าหมายต่ำกว่า Lv 20 | ได้รับความคุ้มครอง (`protected`) |
| ในเมือง | ปลอดภัยเสมอ (`safe`) |
| ปาร์ตี้เดียวกัน | ตีกันไม่ได้ (`party`) |
| ผู้มาเยือน (ไม่ล็อกอิน) | ไม่เข้าร่วม PK (`guest`) |
| ดวล | ทุกเลเวล ต้องท้าและรับคำท้า ผู้แพ้เหลือ 1 HP ไม่มีบาปบุญ ระหว่างดวลตีได้เฉพาะคู่ดวล |

ผู้เล่นที่ PK ได้ในจุดที่ยืนอยู่จะมีคำว่า **PK** หน้าชื่อ

## การตัดสินเมื่อมีคนตายจาก PK

ตรวจตามลำดับ:

1. ผู้ตายเป็น **หัวแดง** (บาป ≥ 100) → **ปราบทรชน** ผู้สังหารได้บุญ `20 + บาปของผู้ตาย × 0.2` และนับ "ปราบหัวแดง" ทั้งห้องได้ยินข่าว
2. ผู้ตายตีผู้สังหารก่อนภายใน 60 วินาที → **ป้องกันตัว** ไม่ได้บาปไม่ได้บุญ
3. นอกนั้น → **ฆ่าผู้บริสุทธิ์** ผู้สังหารได้บาป +50 และนับ "สังหารผู้บริสุทธิ์"

บาปลดลง 1 แต้มทุกครั้งที่ปราบมอนสเตอร์ บุญสะสมไปตลอดไม่ลด

## ช่วงแต้ม

แต้มเป็นจำนวนเต็มตั้งแต่ 0 ขึ้นไป ไม่มีเพดาน เก็บในเซฟตัวละคร (`rec.sin`, `rec.merit`)

### บาป → สีชื่อและยศฝั่งมืด

| บาป | ยศ | สีชื่อ |
| --- | --- | --- |
| 0 | – | ปกติ |
| 1–99 | ผู้มีมลทิน | ส้ม |
| 100–299 | อ้ายเสือ | แดง (หัวแดง) |
| 300–799 | เสือร้าย | แดง |
| 800–1,999 | ขุนโจร | แดง |
| 2,000+ | พญามาร | แดง |

### บุญ → ยศฝั่งธรรม (แสดงเมื่อบาปเป็น 0)

| บุญ | ยศ |
| --- | --- |
| 0–99 | – |
| 100–499 | ขุน |
| 500–1,499 | หลวง |
| 1,500–3,999 | พระ |
| 4,000–9,999 | พระยา |
| 10,000+ | เจ้าพระยา |

ถ้ามีบาปแม้ 1 แต้ม ยศฝั่งมืดจะแสดงแทนยศจากบุญ

## ฉายา PK (หมวด "PK · ประลอง")

| ฉายา | เงื่อนไข |
| --- | --- |
| นักประลองหน้าใหม่ · ยอดนักประลอง · เซียนเวทีประลอง | ชนะดวล 1 · 10 · 50 ครั้ง |
| ผู้พิทักษ์ธรรม · นักล่าค่าหัว · มือปราบทรชน | ปราบหัวแดง 1 · 10 · 50 คน |
| ผู้ทรงบุญญาธิการ | สะสมบุญ 1,000 |
| มือเปื้อนเลือด · ทรชนแห่งพงไพร · ยมทูตเดินดิน | สังหารผู้บริสุทธิ์ 1 · 10 · 50 คน |

## ยังไม่มี

- บทลงโทษเพิ่มของหัวแดงเมื่อตาย (เช่น เสียทองมากขึ้นหรือดรอปของ) และการไถ่บาปที่วัด
- ใช้สกิลกับผู้เล่น (ตอนนี้ PK ใช้ตีปกติ ดาเมจครึ่งหนึ่งของที่ตีมอนสเตอร์)
- กระดานอันดับบุญ/บาป
