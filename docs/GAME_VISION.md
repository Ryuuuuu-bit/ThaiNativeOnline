# Game Vision

Thai Native Online is a stylized Thai-fantasy online RPG inspired by the clarity, charm, social feel, and progression readability of classic MMORPGs.

## Pillars
- Thai cultural identity without becoming a historical simulator
- Orthographic / near-orthographic 2.5D gameplay
- Stylized 3D, anime-influenced characters, soft hand-painted environments
- Clear combat and navigation readability
- Peaceful towns contrasted with dangerous wilderness and supernatural zones
- Build one excellent playable region before scaling into a large MMO

## First Production Goal
Create a small vertical slice that already feels like the future game:
- one playable class
- one town/field/forest route
- five normal monsters
- one elite
- one boss
- one NPC hub
- combat, loot, inventory, quest, save foundation
