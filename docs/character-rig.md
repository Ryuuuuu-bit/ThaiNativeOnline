# ระบบตัวละครและ Rig

ตัวละครทั้ง 6 อาชีพสร้างจาก concept sheet แบบ procedural ในโค้ด (`src/characters/`) ทุกตัวใช้โครงกระดูก humanoid เดียวกัน ผิวหนังและเสื้อผ้าเป็น `SkinnedMesh` ผูกกับกระดูกแบบ smooth skinning และท่าทางทั้งหมด bake เป็น `THREE.AnimationClip` มาตรฐาน จึงเล่นด้วย `AnimationMixer` และ export เป็น glTF ได้

ดูตัวละครได้ที่ `characters.html` (ห้องตัวละคร): หมุนกล้อง เปิดดูโครงกระดูก สโลว์โมชัน เล่นทุกท่า และ Export GLB

## อาชีพและท่าเฉพาะ

| อาชีพ | อาวุธ/อุปกรณ์ | ท่า 1 | ท่า 2 | ท่า 3 |
| --- | --- | --- | --- | --- |

| มวยไทย Muay Thai | มงคล ประเจียด ผ้าพันมือ | ตั้งการ์ดยกเข่ากัน Guard Stance | ศอกตัด Elbow Strike | เข่าลอย Flying Knee (เคลื่อนที่) |
| นักฆ่า Assassin | มีดสั้นจับกลับด้าม | หมอบซุ่ม Stealth Crouch | หมุนตัวเชือด Spinning Slash | กระโจนแทง Leap Strike (เคลื่อนที่) |

ทุกอาชีพมี Idle, Walk (1.2 m/s) และ Run (3.1 m/s) ของตัวเอง เช่น มวยไทยเดินในการ์ด นักฆ่าย่อตัวโน้มไปข้างหน้า หมอผีถือไม้เท้าตั้งตรง

## โครงกระดูก

ชื่อกระดูกใช้แบบ Mixamo เพื่อ retarget กับ Blender, Mixamo, Unity หรือ Unreal ได้ทันที

```
Hips
├─ Spine ─ Spine1 ─ Spine2 ─┬─ Neck ─ Head
│                           ├─ LeftShoulder ─ LeftArm ─ LeftForeArm ─ LeftHand ─┬─ LeftHandFingers1 ─ LeftHandFingers2
│                           │                                                   └─ LeftHandThumb1
│                           └─ RightShoulder ─ … (สมมาตร)
├─ LeftUpLeg ─ LeftLeg ─ LeftFoot ─ LeftToeBase
└─ RightUpLeg ─ … (สมมาตร)
```

- ความสูงประมาณ 1.75 m (ในเกมย่อเป็น 0.92 เท่า) สัดส่วนอนิเมะราว 6 หัว
- Rest pose เป็น I-pose: แขนขาห้อยตรง ทุกกระดูกมี rotation เป็น identity แกนของกระดูกจึงตรงกับแกนตัวละคร (+X ซ้ายของตัวละคร, +Y ขึ้น, +Z หน้า)
- กระดูกเสริม (secondary): ชายผ้า ผ้าคาดหัว พู่ ยันต์ ใช้ spring bone จำลองแรงเฉื่อย แรงโน้มถ่วง และชนกับลำตัวและขา (sphere colliders) จึงพลิ้วตามการเคลื่อนไหวจริง
- `BowNock` ของพราน: กลางสายธนูผูกกับกระดูกนี้ และถูกดึงตามมือขวาขณะน้าวสาย

## ข้อต่อตามสรีระ

ท่าทางเขียนเป็นค่ามุมเชิงความหมาย (`src/characters/moves.js`) และถูก clamp ตามช่วงข้อต่อจริงก่อน bake

| ข้อต่อ | ช่วง |
| --- | --- |
| เข่า | งอ 0–150° (งอไปด้านหลังเท่านั้น ไม่มีเข่าแอ่น) |
| ศอก | งอ 0–150°, คว่ำ/หงายแขน ±85° |
| สะโพก | งอ −35–130°, กาง −25–65° |
| ข้อเท้า | −50–30°, นิ้วเท้า −30–75° |
| กระดูกสันหลัง | ก้ม −25–45°, บิด ±40°, เอียง ±25° (กระจายลง Spine/Spine1) |
| คอ / ศีรษะ | ก้มเงย −40–50° / −30–35°, หัน ±60° / ±30° |
| ข้อมือ | งอ −70–80°, เบี่ยง −25–35° |

แขนใช้ swing–twist (ยกแขน/ทิศทาง/บิด) แทน Euler จึงไม่เกิด gimbal lock เวลายกแขนสูง

## การเคลื่อนไหวที่เป็นธรรมชาติ

- **Leg IK สองข้อต่อ**: ท่าทุกท่ากำหนดตำแหน่งเท้าแทนมุมขา ขาคำนวณด้วย IK เข่าชี้ตามปลายเท้า เท้าที่วางบนพื้นจึงอยู่กับที่ไม่ว่าสะโพกจะย่อ บิด หรือโยก
- **Gait แบบ procedural**: ช่วงยืน/แกว่ง (duty factor) ส้นเท้าลงก่อนแล้วม้วนเท้าไปถีบที่ปลายเท้า สะโพกต่ำสุดตอนสองเท้าแตะพื้น (เดิน) หรือตอนรับน้ำหนัก (วิ่ง) แขนแกว่งสวนขา ลำตัวบิดสวนสะโพก ศีรษะชดเชยให้มองตรง
- **ความเร็วตรงกับเท้า**: phase ของ walk/run ผูกกับความเร็วที่ตัวละครเคลื่อนจริงในเกม และผสมระหว่าง idle, walk และ run ตามความเร็ว
- **Spline แบบ monotone**: คีย์เฟรมต่อเนื่องไม่สะดุด ไม่ overshoot และค่าที่คงที่ระหว่างคีย์ (เช่น เท้าที่วางอยู่) จะนิ่งสนิท
- **Root motion**: ท่าพุ่ง/กระโดด (Dash Slash, Flying Knee, Leap Strike) แยกระยะเคลื่อนที่ออกจากคลิป เกมจึงเลื่อนตัวละครจริงพร้อมตรวจการชน
- **Toe pivot**: เวลาเขย่งหรือคุกเข่าแบบปลายเท้ายัน ข้อเท้าถูกยกตามมุมเท้าและนิ้วเท้าพับราบกับพื้น

## ตรวจสอบอัตโนมัติ

```sh
npm run check:rig
```

สคริปต์สร้างทุกอาชีพใน Node แล้วไล่ทุกเฟรมของทุกคลิป ตรวจว่า: ชื่อกระดูกไม่ซ้ำ เท้าไม่จมพื้น เข่าไม่งอผิดทางหรือเกิน 150° ศอกไม่เกินช่วง เท้าที่วางบนพื้นไม่ไถลขณะเดิน/วิ่ง IK เข้าถึงเป้าหมาย และคลิปที่วนซ้ำต่อกันสนิท

## นำไปใช้ต่อ

- **ในเกม**: เลือกอาชีพที่แผงตัวละครมุมซ้ายบน กด `1` `2` `3` เพื่อใช้ท่า และกด `Shift` ค้างไว้เพื่อเดิน
- **Export GLB**: ปุ่มในห้องตัวละครส่งออก mesh, skin และทุกคลิป ใช้ใน Blender เพื่อปั้นโมเดลละเอียดทับโครงเดิม หรือใช้ใน engine อื่น (spring bone ถูก export เป็นกระดูกธรรมดา แรงฟิสิกส์ต้องตั้งใหม่ใน engine ปลายทาง)
- **เพิ่มท่าใหม่**: เพิ่ม object ใน `skills` ของอาชีพใน `moves.js` (คีย์เฟรมเขียนเฉพาะค่าที่เปลี่ยน) แล้วรัน `npm run check:rig`
- **เปลี่ยนเป็นโมเดลจากศิลปิน**: โมเดลที่ rig ด้วยชื่อกระดูกชุดเดียวกันและ rest pose แบบ I-pose ใช้คลิปที่ bake ไว้ได้โดยตรง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `skeleton.js` | กระดูก ช่วงข้อต่อ การแปลงท่าเป็น rotation และ leg IK |
| `builder.js` | สร้าง skinned tube, แถบผ้า, ribbon, spring chain และรวม mesh ตามวัสดุ |
| `body.js` | สัดส่วนร่างกาย ใบหน้า ทรงผม และ helper เครื่องแต่งกาย |
| `classes.js` / `props.js` | ชุดและอาวุธของแต่ละอาชีพ |
| `moves.js` | ท่ายืน สไตล์การเดิน/วิ่ง และสามท่าเฉพาะของแต่ละอาชีพ |
| `animation.js` | interpolation, gait generator และการ bake เป็น AnimationClip |
| `character.js` | runtime: blend locomotion, เล่นท่า, root motion, spring, สายธนู |
| `springs.js`, `dog.js`, `vfx.js` | ฟิสิกส์ผ้า สุนัขคู่ใจ และเอฟเฟกต์ของแต่ละท่า |
