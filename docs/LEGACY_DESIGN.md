# Legacy Design Policy

The repository `ThaiNative` and previous design boards are preserved as **Legacy Gameplay Reference**.

Reuse:
- class concepts
- skill concepts
- monsters and mythology
- map progression
- level bands
- quests
- items/economy ideas
- multiplayer/server ideas

Do not inherit automatically:
- old sprite appearance
- old environment visual language
- old UI look
- old asset pipeline

New visual decisions belong to `docs/art/ART_BIBLE.md`.
