# คำสั่งแอดมิน

พิมพ์ในช่องแชทเมื่อเข้าสู่ระบบด้วยบัญชีแอดมิน ใช้ /gm help หรือ /gm help ชื่อคำสั่ง เพื่อดูวิธีใช้

บัญชีเป้าหมายของ admin ใช้ชื่อบัญชีเข้าสู่ระบบ ส่วน goto / summon / give / kick / mute ใช้ชื่อตัวละครออนไลน์

| คำสั่ง | การใช้งาน |
| --- | --- |
| `/gm help [คำสั่ง]` | ดูวิธีใช้คำสั่ง GM |
| `/gm gold [n]` | เพิ่มหรือลดตำลึง · ไม่ใส่ n = +10,000 |
| `/gm lv [n]` | เพิ่มเลเวล (level) · ค่าเริ่มต้น 10 |
| `/gm exp [n]` | เพิ่ม EXP · ค่าเริ่มต้น 1,000 |
| `/gm joblv [n]` | เพิ่ม Job Lv · ค่าเริ่มต้น 10 |
| `/gm stat [n]` | เพิ่มแต้มสถานะ (points) · ค่าเริ่มต้น 10 |
| `/gm item <id\|ชื่อ> [n]` | รับไอเทม · ค่าเริ่มต้น 1 ชิ้น |
| `/gm card <มอน>` | รับการ์ดมอนสเตอร์ · ค่าเริ่มต้น 1 ใบ |
| `/gm refine <ช่อง> [ขั้น]` | ตั้งขั้นตีบวกของที่สวม · ค่าเริ่มต้น +4 |
| `/gm heal` | ฟื้น HP/MP |
| `/gm hp [%]` | ตั้ง HP · ค่าเริ่มต้น 100% · 0 = หมดสติ |
| `/gm god` | สลับอมตะจนออกเกม |
| `/gm find <คำ>` | ค้นหาไอเทมและมอนสเตอร์ |
| `/gm map <แมพ> [x z]` | ย้ายแมพ |
| `/gm who` | ดูผู้เล่นออนไลน์ |
| `/gm goto <ชื่อ>` | ไปหาผู้เล่น |
| `/gm summon <ชื่อ>` | เรียกผู้เล่น |
| `/gm give <ชื่อ> <gold\|id> [n]` | มอบตำลึงหรือไอเทม |
| `/gm kick <ชื่อ> [เหตุผล]` | ให้ออกจากเกม |
| `/gm mute <ชื่อ> [นาที]` | ระงับแชท · ค่าเริ่มต้น 10 นาที |
| `/gm unmute <ชื่อ>` | คืนสิทธิ์แชท |
| `/gm killall` | กำจัดมอนในแมพและแชนแนล |
| `/gm say <ข้อความ>` | ประกาศถึงทุกคน |
| `/gm time <ชั่วโมง>` | ตั้งเวลาโลก |
| `/gm admin <add\|remove\|list> [accountId]` | จัดการด้วย accountId · add/remove ต้องระบุบัญชี · list ดูรายการ |

level ใช้แทน lv ได้ และ points ใช้แทน stat ได้ คำสั่งไม่แยกตัวพิมพ์เล็ก/ใหญ่

แอดมินหลักจาก ADMIN_IDS / GM_ID ถอนผ่านคำสั่งไม่ได้ สิทธิ์ที่เพิ่มผ่านคำสั่งจะบันทึกใน PostgreSQL และปรับคนที่ออนไลน์ทันที โหมดทดสอบ MemoryStore เก็บสิทธิ์ได้เฉพาะระหว่างโปรเซสทำงาน
